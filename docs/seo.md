# SEO review — September 16, 2026

Reviewed the local Astro source and production build against Google Search
Central guidance. Live HTTP status codes, redirects, indexing, and Search Console
data could not be verified from this environment. Changes take effect after deployment.

## Implemented

- Page titles now include Leon Lenk; `/self/` uses `About Leon Lenk`.
- The homepage, section listings, and published articles have distinct descriptions.
- Added JSON-LD: `WebSite` on the homepage, `BlogPosting` on articles,
  `ProfilePage` with a `Person` on `/self/`, and breadcrumbs on section/article pages.
- Article authors are visible and link to `/self/` when they identify Leon.
  Publication and optional modification dates use the existing frontmatter.
- Added `max-image-preview:large` to permit large image previews.
- Made trailing slashes explicit to match the existing canonical links and directory output.
- Excluded the legacy `/self/about/` redirect from the generated sitemap.
- Renamed Philosophy to AI at `/ai/`, without retaining the old route or a redirect.
  The sitemap includes `/ai/` and excludes `/philosophy/`.

The sitemap is generated by `@astrojs/sitemap` on every `pnpm build`. Its entry
point remains `https://www.leonlenk.com/sitemap-index.xml`, already advertised by
`public/robots.txt`. The current build contains 10 canonical page URLs, including
`/self/`. Draft posts and generated social images are absent. Do not edit the
ignored `dist/` files by hand.

No fabricated `lastmod`, `priority`, or `changefreq` values were added. Google
ignores the latter two; `lastmod` should only reflect a reliably tracked significant
change. When substantially updating an article, set its `updatedDate` frontmatter
to the actual update date so the visible date and structured data stay aligned.

## Remaining improvements, in priority order

1. After deployment, verify the domain in Google Search Console, submit
   `sitemap-index.xml`, and inspect the homepage, `/self/`, and the drawing article.
   Check the selected canonical and rendered content. Sitemap submission does not
   guarantee indexing.
2. Add a short, visible introduction to the homepage describing Leon and the site's
   subjects, with a descriptive link to the profile or research page. The current
   homepage has server-rendered navigation links, but little explanatory text and
   a visually hidden H1. Make this useful to visitors, rather than adding hidden
   keyword text. This is a visual/content decision left for a separate change.
3. Publish useful content in Food and AI. Their current empty states offer
   little reason to appear in search; consider `noindex` and sitemap exclusion if
   they will remain empty for a long time.
4. Check mobile Core Web Vitals and the homepage's initial loading screen in
   PageSpeed Insights/Search Console. The page can initially hide content for up
   to four seconds while its animation starts. This review did not measure live
   performance; existing performance work is documented separately.
5. Check that HTTP, the non-www domain, and any accessible GitHub Pages hostname
   consistently redirect to the HTTPS www domain. Confirm missing URLs return
   HTTP 404. Hosting-level behavior requires live verification.
6. Run representative deployed pages through Google's Rich Results Test. JSON-LD
   is valid in the local build, but rich-result eligibility and actual appearance
   are determined by Google. For article imagery, consider representative artwork
   in additional aspect ratios beyond the existing generated 1200 × 630 cards.

## Validation

`pnpm check`, `pnpm lint`, `pnpm test` (three tests), and `pnpm build` passed.
The build reported font-cache permission messages from the sandbox while still
successfully generating its social images.

Parsed all 10 sitemap pages and checked canonical agreement, unique nonempty
descriptions, one H1 each, parseable JSON-LD, and existing social image files.
Confirmed the legacy about page contains a redirect and `noindex`, and both sitemap
XML files parse successfully. This is local output validation, not a Google crawl.

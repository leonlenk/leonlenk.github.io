# Links and notes

Links use ordinary underlined text, without hover previews.

Write footnotes using named Markdown references:

```md
Here is a thought worth expanding.[^detail]

[^detail]: Extra context, with an optional [source](https://example.com).

    A second paragraph can be indented by four spaces.
```

Notes sit in the right margin when there is enough room, aligned to their first
reference and spaced to avoid overlap. Smaller windows and pages without
JavaScript show endnotes. Each note includes a return link; repeated references
share one note. Note numbers and links are generated by Markdown.

The About page’s webring uses the original 88×31 badges hosted by each site,
recovered from `main` (`02952af`). Keep their image URLs and native dimensions
when editing the links; the PepperSalt GIF retains its animation.
